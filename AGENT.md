# AGENT

This repository is a fork of the large QMK upstream codebase.

The parts that are most interesting here are:
- `keyboards/ferris/` for Ferris Sweep keyboard definitions and board-level behavior.
- `keyboards/ferris/keymaps/christnil/` for the personal keymap, layers, and local README notes.

Current hardware/context:
- I currently use a Ferris Sweep keyboard.
- I maintain and iterate on my own layout in `keyboards/ferris/keymaps/christnil/`.
